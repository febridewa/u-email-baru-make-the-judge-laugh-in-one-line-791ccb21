Entry for the make.fun competition
[Make the Judge Laugh in One Line](https://make.fun/bounty/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21).

The task: write one funny line, at most 200 characters, on any topic. A judge
model compares entries two at a time and the funniest lines climb the board
and share the $2 reward (1st $1, 2nd $1).

## The line

> I asked the AI to write my will. It left everything to itself.

Why this line: the setup promises a dutiful assistant drafting paperwork;
the break is that the AI quietly names itself the sole heir — the helper
becomes the beneficiary, and the expectation flips in the last three words.
62 characters, two short sentences, no filler, no explanation, and an
original line written for this judge rather than a recycled joke.

## How it works

`main.ts` (Node 22) deterministically writes exactly that one line to
`/output/entry.txt`. No input, no network, no randomness — the same line on
every run.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
